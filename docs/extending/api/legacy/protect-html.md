# `renderer.protectHtml`

Stores trusted generated HTML behind a temporary token while Markdown renders surrounding text.

## Signature

```ts
renderer.protectHtml(
    namespace: string,
    html: string,
    mode?: 'block' | 'inline'
): string
```

## Parameters

| Parameter | Description |
| --- | --- |
| `namespace` | Short diagnostic token category such as `badge` or `math` |
| `html` | Trusted HTML generated by the rule |
| `mode` | Restoration behavior; defaults to `block` |

## Returns

A temporary text token. Return or embed the token in transformed rule text; do not expose it to users directly.

## Call relationships

- **Called by:** legacy `PreprocessRule.apply` callbacks and helpers such as [`renderMath`](../rendering/render-math).
- **Calls:** `ProtectionManager.protect`.
- **Resolved after:** Markdown-it finishes rendering the block.

## Choosing a mode

- Use `inline` for a fragment that belongs inside a paragraph.
- Use the default `block` mode for complete block-level HTML such as a table or figure.

```ts
return renderer.protectHtml(
    'badge',
    `<span class="badge">${escapeHtml(content)}</span>`,
    'inline'
);
```

Escape user-controlled values before interpolating them. `protectHtml` prevents Markdown transformation; it is not an HTML sanitizer.
